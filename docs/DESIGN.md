# Дизайн Shared

На главной одна колонка шириной до 720 px. Вверху название, выход и открытая форма с полем текста. Кнопка «Прикрепить файл» добавляет один файл. При наличии файла текст сохраняется как необязательная подпись.

Заметки и файлы идут в едином списке от новых к старым. Пагинация появляется, когда записей больше одной страницы.

| Элемент | Оформление |
| --- | --- |
| Фон | `#f8f9fc` |
| Форма | `#ffffff` |
| Текст | `#20242c` |
| Вторичный текст | `#5c6474` |
| Акцент | `#234ccb` |
| Шрифт | Segoe UI или системный sans-serif |
